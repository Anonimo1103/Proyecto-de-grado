# Plataforma Web para la Gestión de Tareas Académicas

**Proyecto de Grado — Ingeniería de Sistemas | UNAD**

## Descripción
Plataforma web para la gestión de tareas académicas y seguimiento del rendimiento estudiantil. Permite a los estudiantes organizar sus actividades y a los docentes monitorear el avance del grupo.

## Funcionalidades
- Registro e inicio de sesión por rol (Estudiante / Docente)
- Gestión de tareas con estados: Pendiente, En Progreso, Completada
- Calendario interactivo con semaforización de fechas
- Dashboard de rendimiento académico
- Persistencia de datos (las tareas se conservan al cerrar el navegador)
- Panel docente con analítica de aprendizaje y alertas

## Cómo usar
1. Descarga o clona el repositorio
2. Abre `index.html` en cualquier navegador moderno (Chrome, Firefox, Edge)
3. No requiere instalación ni conexión a internet
